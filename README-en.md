# Taça das Copas

"Taça das Copas" is a classroom's competition project from Etec "Deputado Ary de Camargo Pedroso", by the 2025 student union "Nova Geração".

## What's it?
Is a points management system for a school's classroom competition. Each class will gain a number of points based on completed tasks, like exams performance, best grades, best behavior, interdisciplinary projects, etc.

## Interactions
Users can access the system freely. When it is accessed, there will be a podium showing a "top three classes" and a table showing the school's overall score. The administration section can only be accessed by the student council leader, the developer, and the school administration.

[Project link](tacadascopas.vercel.app)

### Notes
During the development process of this small-scale system, I learned some interesting technologies like React and TailwindCSS. I was able to learn how to use third-party login system, like Firebase, which was used for admin authentication and data storage.
