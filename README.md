# Taça das Copas

O Taça das Copas é um projeto de competição entre salas da Etec "Deputaro Ary de Camargo Pedroso", promovido pelo Grêmio Estudantil 2025 "Nova Geração".

## O que ele é
É um sistema para o gerenciamento de pontos em uma competição entre as salas de aula da escola.
Cada sala ganharia uma determinada quantidade de pontos baseado em atividades exercidas, como desempenho em provas, melhores notas, melhores comportamentos, projetos inter-diciplinares, etc.

## Interações
Os usuários podem acessar o sistema livremente, nele há um pódio, mostrando um "top 3 salas" e uma tabela, mostrando a pontuação global da escola.
A seção de administação só pode ser acessada pelo lider do grêmio, o desenvolvedor e a direção escolar.

[Link de acesso](https://tacadascopas.vercel.app/)

### Notas
Durante o desenvolvimento desse simples sistema, pude aprender diversas tecnologias interessantes, como o React e TailwindCSS. Aprendi também a utilizar sistemas de login de terceiros, como o Firebase, que serviu para a autenticação de uma conta de administrador e para armazenar os dados.
